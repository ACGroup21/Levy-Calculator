Six type pairings, in context

Each pairing is broken out by role — page title, step title, card heading, body, subtitle, caption and button, then the mono side: eyebrows, chips, figures and rule expressions. Judge one role at a time; the assembled block at the foot of each shows them working together. Identical content throughout, so the only thing changing is the type.

These load from Google Fonts. If your network blocks them you would be judging fallbacks without knowing, so each specimen is checked at runtime and flagged below.
